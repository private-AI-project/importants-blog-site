# 도구 후보 발굴 기록

도구 후보 발굴 에이전트가 회차별로 제안한 후보를 누적 기록한다. 실제 구현 여부와 무관하게 검토 이력을 남긴다.

---

## 2026-09-01 회차

### 1. 청년미래적금 정부 기여금 계산기

- **대상 블로그**: 혜택줍줍
- **입력값**:
  - 만 나이 (병역 기간 최대 6년 차감 반영 여부)
  - 본인 소득 (총급여/종합소득 — 일반형·우대형 판정용)
  - 가구 소득 (기준 중위소득 대비 %)
  - 월 납입액 (최대 50만원)
- **출력**: 일반형/우대형 가능성 범위 안내, 3년 만기 시 원금, 정부 기여금 총액, 비과세 혜택 여부
- **계산 로직 요약**: 3년(36개월) 자유적립식, 월 최대 50만원 납입. 정부 기여금은 월 납입액의 6%(일반형, 월 최대 3만원) 또는 12%(우대형, 월 최대 6만원)를 36개월 누적. 여기에 이자소득세 면제를 안내로 덧붙인다.
- **근거 글**: `2026-08-28-youth-future-savings-round2.md` — "매달 50만원씩 3년을 채우면... 정부 기여금 108만원(월 3만원씩 36개월)", "우대형이면 기여금이 216만원"
- **시즌성**: 1차 모집(6월, 234만 명 신청)에 이어 추가 모집이 "이르면 9월, 늦어도 10월"로 보도됨. 확정 공고 전이지만 시기가 임박
- **난이도**: 하 (단순 비율 계산, 캡만 있는 구조)
- **유지보수 리스크**: 추가 모집의 정확한 자격 요건(가구 소득 %, 병역 공제 세부 규정)이 공식 공고에서 조정될 수 있음. 계산 로직 자체(기여금 6%/12%)는 1차 때 이미 확정된 값이라 안정적
- **왜 지금인가**: 1차 신청 234만 명이 몰렸던 인기 상품이고, 추가 모집 임박 보도로 "내가 얼마나 받을 수 있는지" 검색 수요가 곧 급증할 것으로 예상됨

### 2. 육아휴직 급여 계산기

- **대상 블로그**: 홈로그
- **입력값**:
  - 통상임금 (월)
  - 총 휴직 기간 (개월)
  - 부부 동시 사용 여부 (6+6 부모육아휴직제 해당 여부)
  - 한부모 여부
- **출력**: 구간별(1~3개월/4~6개월/7개월 이후) 월 예상 지급액과 총 수령액
- **계산 로직 요약**: 1~3개월은 통상임금 100%(월 상한 250만원), 4~6개월은 100%(상한 200만원), 7개월부터는 80%(상한 160만원). 부모가 함께 쓰면 6+6 특례로 첫 6개월 상한이 매달 계단식으로 올라(1개월 250만원 → 6개월 450만원) 적용되고, 한부모는 1~3개월 상한이 300만원으로 올라간다.
- **근거 글**: `2026-08-31-parental-leave-benefit-2026.md` — 월별 지급 비율·상한액 표 전체, 6+6 제도 및 한부모 특례 문단
- **시즌성**: 뚜렷한 성수기는 없으나 연중 상시 검색 수요가 크고, 최근 사흘(8/29~31) 사이 배우자 출산휴가·육아기 근로시간 단축·육아휴직 급여 글이 연달아 쌓여 서로 링크로 이미 연결돼 있음
- **난이도**: 중 (구간별 상한 + 6+6/한부모 특례 분기 처리 필요)
- **유지보수 리스크**: 월 상한액이 매년 1월 개정됨(2025년 기준에서 이미 한 차례 인상). 매년 초 금액 갱신이 필요
- **왜 지금인가**: 육아 관련 글이 최근 집중적으로 쌓여 상호 참조 구조가 이미 만들어져 있고, 세 제도(출산휴가·근로시간단축·휴직급여) 중 검색 수요가 가장 클 급여 계산이 아직 도구화되지 않음

### 3. 경차 유류세 환급액 계산기

- **대상 블로그**: 차곡차곡
- **입력값**:
  - 연비 (km/L)
  - 월 주행거리 (km)
  - 연료 종류 (휘발유/경유/LPG)
- **출력**: 월 예상 환급액, 연간 예상 환급액(한도 30만원 반영), 한도 도달까지 남은 주행거리
- **계산 로직 요약**: 휘발유·경유는 리터당 250원, LPG는 부탄 개별소비세 전액을 환급하며 연간 한도는 30만원. 월 주유량(L) = 월 주행거리 ÷ 연비로 환산한 뒤 리터당 환급액을 곱하고, 연 누적액이 한도를 넘으면 30만원에서 자른다.
- **근거 글**: `2026-08-31-kei-car-fuel-tax-refund.md` — "리터당 250원... 연간 30만원", 연비 15km/L·월 1,000km 주행 예시
- **시즌성**: 뚜렷한 계절 성수기는 없음. 다만 유류세 인하 조치가 9월 30일 종료 예정이라 기름값 관련 검색이 이달 함께 늘어날 가능성
- **난이도**: 하 (단순 비율 계산 + 한도 캡)
- **유지보수 리스크**: 리터당 환급액(250원)과 연간 한도(30만원)는 조세특례제한법 개정 시 바뀔 수 있음. 제도 자체의 적용 기한(2026년 말)을 2029년까지 연장하는 법안이 국회 계류 중이라 제도 존속 여부부터 확인 필요
- **왜 지금인가**: 차곡차곡 블로그에는 아직 도구가 하나도 없음. 계산 로직이 단순하고 수치가 이미 법령·공식 안내로 검증돼 있어 첫 도구로 부담이 적음
