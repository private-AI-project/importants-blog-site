# 도구 후보 발굴 기록

도구 후보 발굴 에이전트가 회차별로 제안한 후보를 누적 기록한다. 실제 구현 여부와 무관하게 검토 이력을 남긴다.

## 2026-09-01 회차

### 혜택줍줍

#### 1. 작년 병원비 환급액 계산기 (본인부담상한제)

- **대상 블로그**: 혜택줍줍
- **입력값**:
  - 건강보험료 소득분위 (1~10분위 중 선택, 모르면 확인 링크 안내)
  - 2025년 한 해 낸 본인부담금 합계 (원, 급여 항목만 — 비급여 제외 안내 필수)
  - 요양병원 120일 초과 입원 여부 (Y/N)
- **출력**: 예상 환급액(원) = 본인부담금 합계 − 해당 분위 상한액(요양병원 초과 입원 시 별도 상한액). 0 이하면 "환급 대상 아닐 가능성" 문구
- **계산 로직 요약**: 소득 10분위별 상한액표(1분위 89만원/141만원(요양병원 초과) ~ 10분위 826만원/1,074만원)에서 해당 분위 값을 찾아 본인부담금 합계에서 단순히 빼는 구조. 조건 분기는 "요양병원 초과 여부" 하나뿐
- **근거 글**: `2026-08-31-medical-cost-cap-refund.md` — "1분위(소득 하위 10%) 89만원 / 141만원(요양병원 120일 초과)... 10분위 826만원 / 1,074만원", "소득 1분위인 사람이 작년에 본인부담금으로 500만원을 냈다면, 상한액 89만원을 뺀 411만원이 돌려받을 돈"
- **시즌성**: 매년 반복 (8월 말 발표 → 9월 초 자동 지급 시작하는 연례 행사)
- **난이도**: 하
- **유지보수 리스크**: 분위별 상한액표는 매년 복지부가 갱신 발표하므로 연 1회 표 업데이트 필요. 로직 자체는 안 바뀜
- **왜 지금인가**: 8월 31일부터 안내문 발송 중이고 9월 2일부터 자동 지급 시작 — 지금이 검색 피크 시점

#### 2. 재산세 분납 가능액 · 연체 가산세 계산기

- **대상 블로그**: 혜택줍줍
- **입력값**:
  - 고지된 재산세액 (원)
  - 납부 기한을 이미 넘겼는지 여부 (Y/N)
  - (넘겼다면) 경과 개월 수 (0~60)
- **출력**: 분납 가능 여부 및 분납 가능 금액(세액 250만~500만원: 250만원 초과분만 / 500만원 초과: 세액의 절반까지), 연체 시 예상 가산세
- **계산 로직 요약**: 분납은 세액 구간에 따른 단순 조건식(250만원 이하는 불가, 250만~500만원은 "세액−250만원", 500만원 초과는 "세액×0.5"). 가산세는 "세액×3%"에, 세액 45만원 이상 구간에서 "세액×0.66%×경과월수(최대 60개월)"를 더하는 2단계 산식
- **근거 글**: `2026-08-27-september-property-tax.md` — "세액이 500만원 이하면 250만원을 넘는 금액을, 500만원을 초과하면 세액의 절반까지를... 나눠 낼 수 있습니다", "납부기한을 하루라도 넘기면 세액의 3%가 납부지연가산세로 붙습니다... 세액이 45만원 이상이면 한 달 지날 때마다 0.66%가 최대 60개월까지 추가됩니다"
- **시즌성**: 연 2회 반복 (7월 1기분, 9월 2기분)
- **난이도**: 하~중
- **유지보수 리스크**: 지방세법 제118조(분납 기준)·지방세기본법 제55조(가산세율) 개정 가능성 — 매년 시행령 확인 필요
- **왜 지금인가**: 9월 2기분(9/16~30) 납부 시즌과 정확히 겹치고, 추석 연휴가 껴 있어 "기한 넘기면 얼마" 계산 수요가 특히 높은 시점

### 차곡차곡

#### 1. 스쿨존 과태료 계산기

- **대상 블로그**: 차곡차곡
- **입력값**:
  - 위반 유형 (속도위반/신호위반/주정차)
  - 속도위반 시 초과 구간 (20 이하/20~40/40~60/60 초과)
  - 단속 방식 (무인카메라=과태료 / 현장적발=범칙금+벌점)
  - 자진납부 여부 (20% 감경 적용 여부)
- **출력**: 예상 과태료 또는 범칙금 금액, 벌점, 자진납부 시 감경된 최종 금액
- **계산 로직 요약**: 법제처 표를 그대로 매핑한 조회형 계산. 속도위반은 4단계 구간별 과태료(7/10/13/16만원)·범칙금(6/9/12/15만원)·벌점(15/30/60/120점), 신호위반은 고정값(과태료 13만원, 범칙금 12만원+벌점 30점), 주정차는 고정값(12만원, 2시간 초과 시 13만원)이며 자진납부 시 과태료 총액의 20%를 감경
- **근거 글**: `2026-08-30-school-zone-fines.md` — "20km/h 이하: 스쿨존 과태료 7만원/범칙금 6만원/벌점 15점" ~ "60km/h 초과: 16만원/15만원/120점" 표, "신호위반은... 과태료 13만원, 범칙금 12만원에 벌점 30점", "승용차 과태료는... 12만원, 2시간 넘게 두면 13만원", "자진납부하면 20%를 감경받는다"
- **시즌성**: 매년 3월·9월 개학철에 단속 강화가 반복되는 뚜렷한 연 2회 패턴
- **난이도**: 하 (테이블 조회 + 20% 감경 곱셈, 다단계 조건분기 없음)
- **유지보수 리스크**: 낮음 (법 개정 시 금액표 갱신 필요)
- **왜 지금인가**: 2학기 개학 직후로 학부모·통근자의 재인지 수요가 연중 가장 높은 시점과 정확히 일치

#### 2. 자동차 정기검사 만료일·과태료 계산기

- **시즌성**: 개인별 2년 주기라 특정 달에 몰리진 않는 evergreen형이나, 등록 대수가 많아 연중 항상 일정 수요
- **난이도**: 하
- **유지보수 리스크**: 낮음 (2025년에 이미 한 차례 개정된 전례가 있어 향후 재개정 가능성 존재, 연 1회 확인 권장)
- **왜 지금인가**: 강한 계절 트리거는 없지만 실용성이 높아 evergreen 트래픽·체류시간 확보용 도구로 적합

#### 3. 경차사랑카드 유류세 환급액 계산기

- **대상 블로그**: 차곡차곡
- **입력값**:
  - 월 평균 주행거리(km) 또는 월 주유량(L) 중 택1
  - 연비(km/L, 주행거리 입력 시 필요)
  - 유종(휘발유/경유/LPG)
- **출력**: 예상 월·연간 환급액, 연 30만원 한도 도달 여부 및 한도까지 남은 주유량
- **계산 로직 요약**: 연간 주유량(L) = 월 주행거리 ÷ 연비 × 12, 환급액 = 연간 주유량 × 250원(휘발유·경유), 연 30만원 상한 적용. LPG는 리터당 정액이 근거 글에 없어 "추가 조사 필요"로 별도 표시
- **근거 글**: `2026-08-31-kei-car-fuel-tax-refund.md` — "휘발유와 경유는 리터당 250원... 한도는... 연간 30만원", "연비를 리터당 15km로 잡고 한 달에 1,000km를 달리면... 약 67리터... 리터당 250원씩이면 한 달에 17,000원 정도, 1년이면 20만원쯤"
- **시즌성**: 제도 자체는 상시지만, 진행 중인 유류세 한시 인하(9/30 종료 예정) 화제성과 맞물려 관심도 상승
- **난이도**: 하 (단순 비례식 + 상한 캡, LPG만 예외 처리)
- **유지보수 리스크**: 낮음. 단, 근거 조항(조세특례제한법 제111조의2)이 2026년 말 일몰 예정(연장안 국회 계류 중)이라 2027년 이후 존속 여부 재확인 필요
- **왜 지금인가**: 유류세 인하 관련 뉴스 흐름(9/30 만료 임박)과 맞물려 "경차는 세금으로 얼마나 더 아끼는지" 검색 수요 발생

**참고**: 채권환급(car-bond-refund)은 로직은 단순하나 계절 스파이크가 없는 순수 evergreen 주제라 제외했고, 면허갱신 생일(license-renewal-birthday)은 2026년 신제도라 시의성은 높지만 나이 구간(65/75세)·1종/2종·경과조치가 겹쳐 다단계 조건 분기라 이번 회차에서는 제외했다.

### 홈로그

#### 1. 육아기 근로시간 단축 급여 계산기

- **대상 블로그**: 홈로그
- **입력값**:
  - 통상임금 (월, 원)
  - 단축 전 주당 소정근로시간 (시간)
  - 단축 후 주당 근로시간 (시간)
- **출력**: 예상 월 급여 보전액(원) — "실제 수당·상여 구성에 따라 다를 수 있는 추정치" 문구 필수
- **계산 로직 요약**: 줄어든 시간(단축 전−단축 후) 중 최초 10시간분은 `min(통상임금, 250만원)`을 기준으로 100%×(10÷단축 전 근로시간)을 곱해 계산(하한 50만원), 10시간 초과분은 `min(통상임금×0.8, 160만원)`을 기준으로 같은 비례식을 적용해 두 값을 합산
- **근거 글**: `2026-08-30-reduced-work-hours-childcare-2026.md` — "매주 줄인 시간 중 최초 10시간까지는 통상임금의 100%를 기준으로 계산합니다. 이때 기준이 되는 통상임금의 상한이 월 250만원, 하한이 50만원입니다. 10시간을 넘겨 줄인 부분은 통상임금의 80%가 기준이고 상한은 월 160만원입니다." + 예시(통상임금 300만원, 40→20시간 단축 → 62.5만원+40만원=102.5만원)
- **시즌성**: 학기 시작(3월·9월)마다 하교시간 대응 수요 반복, 초등 6학년(만 12세)까지 매년 대상
